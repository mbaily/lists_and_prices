Project = the exact resolved version in package-lock.json, not the minimum in
package.json. Declared = the requested semver range. All 38 direct packages in

Latest stable for npm = the publisher's current "latest" dist-tag, checked against
the public npm registry; all returned versions were non-prerelease releases.
Latest versions are compared globally, even when outside the declared range.
Runtime/system versions are observations from this development machine; they
are not project pins or measurements of the deployed production server.
Source references identify the upstream registry or official release page.

   TypeScript's latest stable is 7.0.2. The installed @vite-pwa/sveltekit 1.1.0

   Sources: [S09] [S17] [S10]

   Source: [S34]
