AGREED BEHAVIOR

- The web app supports folders inside both plain and priced lists. No terminal
  UI feature is requested.
- Add item gains a third mode, Folder, alongside Todo and Note. Entering a name
  creates a folder in the current view. A folder appears as a folder icon and
  name in the row order. Clicking it opens the folder using the same list
  interface and adds a level to the breadcrumb.
- A list folder may contain nested folders, todos, notes, subtasks, subnotes, and
  heading rows. A folder can belong to a list root or another folder in that
  list. Whole lists stay in the existing home folder hierarchy.
- Select items offers an incrementally searchable destination picker with List
  root and every folder in the owning list, including folders elsewhere in its
  tree. Show full paths to distinguish repeated names. Moving to List root
  from any depth means the root of the owning list.
- Folder rows can be selected and moved with their full contents, both within
  the list and via existing cross-list actions. Prevent moving a folder into
  itself or a descendant. A folder can be marked as a destination for moves
  from another list. Normal bulk move semantics apply to tasks and notes:
  selecting a parent carries its descendants, and selecting a child by itself
  detaches it at the destination while preserving its own descendants.
- Deleting a non-empty folder asks for confirmation and then deletes its
  contents recursively.
- Checked counts, price totals, checked filters, bulk actions, spreadsheet
  copies and journal copies are scoped to the view that is open. Each view
  has its own checked filter. Folders use the owning list's pricing and
  checkbox settings.
- Global search finds folder names and items within folders. Search results
  and item links open the correct folder with its full breadcrumb. Clipboard
  JSON export and import recreate nested folders and their contents.
